# Show offloaded titles and ask Curator to get them back

Build: 299
Issue: #1

**Status:** built; physical device acceptance pending.

A title whose files Curator removed to free disk space stays in the library.
iPhone, iPad and Apple TV dim its card, mark it Offloaded, and replace Play with
a Get it back action for admins; the item page shows Curator's live state while
it is open. The library filter can show present or offloaded titles. No device
deployment is claimed by this note.
