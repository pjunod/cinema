# Show each version's Dolby Vision line on iPhone and iPad

Issue: #1949

The iPhone and iPad version chooser is now a list of rows in the Media
section instead of a menu. Each row shows the version's full filename and,
beneath it, its Dolby Vision facts as the server words them, for example
"Profile 7 · FEL · full enhancement layer · level 6 · HDR10 base". The menu
showed only the first line of a row and cut long release names, so the
Dolby Vision line added in #1926 never appeared there. Apple TV's Version
panel is unchanged. No device deployment is claimed by this note.
