# Make every Apple TV screen reachable and readable with the Siri Remote

Build: 259
Issue: #1130

Choice menus own native focus, select the current value and return to their
opener on Back. Library tools are reachable from every row at any library
size. Hidden playback no longer paints a white focus box over the video, and
reporting lives in More. The full Live TV guide stays responsive with visible
focus across all channels, follows Now until paged, and Live transport
controls move exactly one step per press. Root tabs, Search, recordings,
Settings and Help, remote management, Shared playback and long About text
follow the same entry and Back rules.
