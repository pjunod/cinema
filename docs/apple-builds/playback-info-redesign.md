# Playback information hierarchy

Build: 161
Issue: #321

Apple playback information now uses Overview, Details, Diagnostics and Compact
across library playback and Live TV. Player-reported resolution remains visible
when unavailable, source and stream observations have distinct labels, and the
phone/tablet/TV layouts use readable grouped content. See the
[implementation record](../clients/PLAYBACK-INFO-REDESIGN.md) for semantics and
qualification evidence. Merge does not publish or install this build.
