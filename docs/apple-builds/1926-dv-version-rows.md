# Show each version's Dolby Vision in the version picker

Issue: #1926

The iPhone and iPad version picker and the Apple TV Version panel now show
each version's Dolby Vision facts under its name, for example "Profile 7 ·
FEL · full enhancement layer · level 6 · HDR10 base", worded by the server.
The selected version also lists how it plays on each of the account's
devices, with a warning mark on a fallback or a dropped enhancement layer:
in the Media section on iPhone and iPad, and under the action row on Apple
TV. No device deployment is claimed by this note.
