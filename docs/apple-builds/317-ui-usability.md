# Mobile continuation and recording usability

Build: 159
Issue: #317

Share series continuation with iPhone and iPad, name its episode target,
make recording filters fit touch screens, expose recording activity from
Home, and retain a visible focus treatment on Apple TV. Home adds Search
and secondary destination shortcuts; continuation cards separate episode
copy from remaining time. Library title filtering and exact search ordering
make browsing easier without changing the underlying APIs.

See the [mobile review](../clients/MOBILE-UI-USABILITY-AUDIT.md) and
[delivery ledger](../clients/WEB-UI-IMPLEMENTATION-STATUS.md) for evidence
and coverage limits. This source build is not an App Store upload.
