# Browse native libraries in grouped horizontal rows

**Status:** built — merged in [PR #823](http://forge.lan:3000/noirr/plurx/pulls/823);
physical-device deployment is not claimed.

Build: 209
Issue: #821

Movies, shows, and other collections now default to horizontal rows grouped
by the selected title, year, recording date, resolution, or recently-added
sort. Jump to a group or open View all; Grid remains a remembered choice.
Rows load the whole catalog through the existing pager, keep partial results
visible, and offer Retry after a failed page. The shared Apple screens cover
iPhone, iPad, and Apple TV.

Implementation and acceptance are tracked in
[the grouped-library status page](../clients/GROUPED-LIBRARY-ROWS-STATUS.md).
