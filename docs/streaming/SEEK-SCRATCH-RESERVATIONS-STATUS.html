The limit this ships with

Transcoded output still reserves the whole per-session ceiling. FFmpeg's -f hls writes its own segment and playlist files, and there is no Rust hook before those writes; a measurement taken afterwards can only discover an overrun. Three candidate mechanisms were weighed — an owned output boundary (a substantial media-pipeline change), a hard writable quota (RLIMIT_FSIZE is per file; ffmpeg -fs counts cumulative muxed bytes and would truncate a long film; project quotas need privileged provisioning), and an enforced envelope (the timers are cadences, not proven maxima) — and none passed. The incident path and the more-than-three-producers case are both the copy path, so the repair reaches them; this is named rather than hidden, on the Developer tab too.
